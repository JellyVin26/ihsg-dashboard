# 📈 IHSG Dashboard

A modern web dashboard for monitoring and analyzing the **Indonesia Stock Exchange Composite Index (IHSG)**. This project provides a visual overview of market movements, helping users better understand Indonesian stock market trends through interactive data visualization.

🌐 Live Demo: https://ihsg-dashboard.vercel.app/

## 🚀 Features

### 📊 Market Overview
- Displays IHSG market information in an organized dashboard layout.
- Provides users with a quick overview of current market conditions.
- Helps investors monitor market direction without manually checking multiple sources.

### 📈 Interactive Data Visualization
- Visual representation of stock market trends.
- Makes complex financial data easier to understand.
- Allows users to identify market patterns and movements.

### 🖥️ Responsive Web Interface
- Clean and user-friendly dashboard design.
- Optimized for different screen sizes.
- Provides a smooth experience across desktop and mobile devices.

### ⚡ Backend Data Processing
- Python-based backend server for handling application logic.
- Separates data processing from frontend visualization.
- Enables easier future expansion of financial analysis features.

## 🛠️ Tech Stack

### Frontend

## ⚙️ Installation & Setup

### 1. Clone Repository

```bash
git clone https://github.com/JellyVin26/ihsg-dashboard.git
```

Navigate into the project folder:

```bash
cd ihsg-dashboard
```

---

### 2. Install Python Dependencies

Create a virtual environment:

```bash
python -m venv venv
```

Activate the environment:

**Windows**
```bash
venv\Scripts\activate
```

**Mac/Linux**
```bash
source venv/bin/activate
```

Install required packages:

```bash
pip install -r requirements.txt
```

---

### 3. Run Application

Start the backend server:

```bash
python server.py
```

Open your browser:

```
http://localhost:5000
```

## 🎯 Purpose

The IHSG Dashboard was created to provide a simple and accessible way to visualize Indonesian stock market movements.

Traditional financial platforms often display large amounts of information that can overwhelm beginner investors. This dashboard focuses on presenting important market insights through a clean interface, allowing users to quickly understand market trends.
